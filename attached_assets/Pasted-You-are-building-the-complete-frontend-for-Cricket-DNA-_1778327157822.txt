You are building the complete frontend for "Cricket DNA" — a Next.js 14 React app 
that clusters cricketers by HOW they play, not their position. The emotional anchor 
of this entire project is Virat Kohli. Every design decision should reflect obsession, 
precision, and the weight of greatness.

TECH STACK (frontend only — no backend)

- Next.js 14 App Router
- TypeScript
- Tailwind CSS + shadcn/ui
- Framer Motion (for scroll-based animations)
- GSAP + ScrollTrigger (for stacking cards, horizontal scroll, sticky switches)
